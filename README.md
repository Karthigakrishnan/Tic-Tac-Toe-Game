Tic-Tac-Toe Game
  A simple two-player console-based Tic-Tac-Toe game written in Python. Players take turns to mark the spaces in a 3x3 grid, and the first player to align three of their marks (horizontally, vertically, or diagonally) wins.

Features
  Two-player gameplay
  Interactive turn-based system
  Check for winner after every move
  Displays the game board after each turn
  Detects draw if the board is full and no player has won

Requirements
  Python 3.x

How to Run
  Clone the repository:
      git clone https://github.com/yourusername/tic-tac-toe.git
  Navigate to the project folder:
      cd tic-tac-toe
  Run the game script:
      python Code.py

Game Rules
  The board consists of a 3x3 grid.
  Players alternate marking spaces on the grid with 'X' and 'O'.
  The first player to align three marks horizontally, vertically, or diagonally wins.
  If all spaces are filled and no player has won, the game ends in a draw.
